Clase 9: Aprendizaje Supervisado - Algoritmos Clásicos

9.1 Regresión Lineal: Fundamentos y Variantes

La regresión lineal constituye uno de los algoritmos de machine learning más fundamentales y ampliamente utilizados, modelando relaciones entre variables predictoras (features) y una variable respuesta continua (target) mediante combinación lineal: y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε, donde β₀ representa el intercept, βᵢ son coeficientes de features, y ε captura ruido aleatorio. El objetivo es estimar parámetros β que minimizan el error cuadrático medio (MSE) entre predicciones ŷ y valores observados y: MSE = (1/n)∑(yᵢ - ŷᵢ)². Este problema de optimización tiene solución analítica mediante ecuaciones normales: β = (X^T X)^(-1) X^T y, donde X es matriz de diseño conteniendo features y y es vector de targets. Alternativamente, métodos iterativos como gradient descent optimizan actualizando parámetros: β ← β - α∇MSE, donde α es learning rate.

La regresión lineal simple con single predictor permite visualización clara: datos plotean en 2D, modelo representa línea que minimiza suma de distancias verticales cuadradas a puntos. El coeficiente β₁ representa pendiente (cambio en y por unidad de cambio en x), β₀ representa intercept (valor de y cuando x=0). La regresión lineal múltiple generaliza a múltiples predictores, permitiendo capturar relaciones complejas where target depende de múltiples factors. Interpretation de coeficientes requiere cuidado: βᵢ representa cambio esperado en target por unidad de cambio en feature i manteniendo otros features constantes (ceteris paribus interpretation). Multicollinearity, correlación alta entre predictores, infla variance de estimadores complicando interpretation; detectable via Variance Inflation Factor (VIF).

Las extensiones de regresión lineal incluyen regresión polinómica que captura relaciones no lineales mediante términos de orden superior: y = β₀ + β₁x + β₂x² + β₃x³ + ..., transformando problema no lineal en x a linear en parámetros β, resolvible con métodos estándar. Regularization techniques previenen overfitting penalizando magnitudes de coeficientes: Ridge regression (L2 regularization) añade penalty ∑βᵢ² fomentando coeficientes pequeños; Lasso (L1 regularization) añade ∑|βᵢ| induciendo sparsity (coeficientes exactamente cero) performing automatic feature selection. Elastic Net combina L1 y L2 penalties balancing benefits. La selección de hyperparameter de regularization λ typically proceeds via cross-validation optimizando trade-off entre bias y variance. Standardization de features (mean 0, variance 1) es importante para regularization ensuring penalties aplican equitably across features con different scales.

9.2 Regresión Logística: Clasificación Probabilística

La regresión logística extiende ideas de regresión lineal a clasificación binaria modelando probabilidad de pertenencia a clase positiva mediante función logística (sigmoid): P(y=1|x) = σ(z) = 1/(1 + e^(-z)), donde z = β₀ + β₁x₁ + ... + βₙxₙ es combinación lineal de features. La función sigmoid mapea valores reales a rango (0,1) interpretable como probabilidad, exhibiendo forma S approach 0 para z→-∞ y 1 para z→+∞. La frontera de decisión occurs donde P(y=1|x) = 0.5, equivalentemente z = 0, representando hyperplane linear en feature space. Aunque nombre sugiere regression, logistic regression es classification algorithm output probability scores usadas para predictions clasificando según threshold (típicamente 0.5).

La estimación de parámetros procede mediante maximum likelihood maximizando probabilidad de observar data dado modelo: L(β) = ∏P(yᵢ|xᵢ,β). En práctica, minimizamos negative log-likelihood (cross-entropy loss): -∑[yᵢlog(ŷᵢ) + (1-yᵢ)log(1-ŷᵢ)], función convexa optimizable via gradient descent. El gradient ∇loss tiene forma simple: ∑(ŷᵢ - yᵢ)xᵢ, permitiendo efficient optimization. No hay closed-form solution como en linear regression, requiring iterative methods. Regularization (L1, L2) prevents overfitting penalizando parámetros grandes, especialmente importante con high-dimensional data.

La generalización multiclase usa regresión logística multinomial (softmax regression) modelando probabilidades para K clases: P(y=k|x) = exp(z_k)/∑exp(z_j), donde z_k = β_k^T x son scores para cada clase. Esto asegura probabilities sum to 1 interpretable como distribution. One-vs-Rest (OvR) approach entrena K binary classifiers, cada uno distinguiendo clase k desde resto; prediction selecciona clase con highest score. One-vs-One (OvO) entrena K(K-1)/2 classifiers, uno por cada par de clases; prediction via majority voting. Las calibration techniques ensure predicted probabilities reflect true likelihoods: Platt scaling fits sigmoid to outputs, isotonic regression fits monotonic function, improving reliability para decision-making requiriendo well-calibrated probabilities.

9.3 K-Nearest Neighbors: Aprendizaje Basado en Instancias

El algoritmo K-Nearest Neighbors (k-NN) constituye método de aprendizaje lazy (basado en instancias) que no construye modelo explícito durante training phase, sino memoriza dataset entero difiriendo computation hasta prediction time. Para clasificar nueva instancia x, k-NN identifica k vecinos más cercanos en training set según distance metric (Euclidean, Manhattan, Minkowski), luego asigna clase mayoritaria entre esos vecinos (classification) o promedio de valores (regression). La simplicidad conceptual y ausencia de training phase hacen k-NN attractive baseline, pero prediction cost escala linearly con training set size, costly para large datasets.

La selección de k balancea bias-variance tradeoff: k pequeño (eg. k=1) produce decision boundaries complejas, altamente flexible capturing local patterns pero susceptible a noise (high variance, low bias); k grande suaviza decisions producing simpler boundaries menos sensitive a individual points pero potentially underfitting (low variance, high bias). Cross-validation guides k selection evaluating performance across range. La choice de distance metric affects neighborhoods: Euclidean distance √∑(xᵢ-yᵢ)² natural para continuous features; Manhattan distance ∑|xᵢ-yᵢ| robust a outliers; Hamming distance for categorical features counting mismatches. Feature scaling (standardization, normalization) es crítica: features con large magnitudes dominate distance calculations, distorting neighborhoods. Weighted k-NN asigna pesos inversely proportional a distance, prioritizing closer neighbors.

Las optimizaciones aceleran nearest neighbor search desde naive O(n) per query: KD-trees partition space recursively enabling O(log n) search en low dimensions pero degrading en high dimensions (curse of dimensionality). Ball trees use hypersphere partitions more effective para high dimensions. Locality-Sensitive Hashing (LSH) approximates nearest neighbors hashing similar items to same buckets con high probability, enabling sublinear query time. Dimensionality reduction (PCA, t-SNE) proyecta data a lower-dimensional space mitigating curse of dimensionality. Applications incluyen recommendation systems (collaborative filtering finding similar users/items), anomaly detection (instances far desde neighbors), image classification (pixel-based similarity). Challenges incluyen computational cost, memory requirements storing entire dataset, sensitivity a irrelevant features, y imbalanced classes donde majority class dominates neighborhoods.

9.4 Support Vector Machines: Maximización de Margen

Las Support Vector Machines (SVM) buscan optimal separating hyperplane maximizando margin, distancia mínima desde hyperplane a nearest training points de ambas classes. Intuitively, large margin increases confidence en predictions, theoretically improving generalization. El hyperplane representa decision boundary: wx + b = 0, donde w es normal vector y b es bias. Training points satisfacen constraints: yᵢ(w·xᵢ + b) ≥ 1, ensuring correct classification con margin. Support vectors, subconjunto de points exactly on margin boundaries (yᵢ(w·xᵢ + b) = 1), solely determine hyperplane; removing other points no afecta model. La formulación primal minimiza ||w||² sujeto a constraints, convex quadratic programming problem solvable via Lagrange multipliers yielding dual formulation expressing w como linear combination de support vectors.

El kernel trick permite SVMs handle non-linearly separable data sin explicit transformation a high-dimensional spaces. Idea clave: dual formulation involves only dot products xᵢ·xⱼ; replacing con kernel function K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ) computes dot products en transformed space implicitly. Popular kernels incluyen: Linear K(x,y)=x·y (no transformation), Polynomial K(x,y)=(x·y+c)^d (polynomial features), RBF (Gaussian) K(x,y)=exp(-γ||x-y||²) (infinite-dimensional space, smooth boundaries), Sigmoid K(x,y)=tanh(αx·y+c) (neural network inspired). RBF kernel particularmente popular for flexibility: hyperparameter γ controls smoothness (small γ→smooth, large γ→wiggly).

Soft-margin SVM relaxa hard constraints permitiendo misclassifications via slack variables ξᵢ: yᵢ(w·xᵢ + b) ≥ 1-ξᵢ, ξᵢ≥0. Objective function añade penalty C∑ξᵢ balancing margin maximization con minimizing violations. Hyperparameter C controls trade-off: large C heavily penalizes errors encouraging hard margin (risk overfitting), small C tolerates errors allowing wider margin (risk underfitting). Cross-validation tunes C y kernel parameters jointly. Multiclass SVM extends via One-vs-Rest o One-vs-One strategies. Applications span text classification, image recognition, bioinformatics. Challenges incluyen computational cost O(n²-n³) para large datasets, memory requirements storing kernel matrix, hyperparameter sensitivity. Approximations (Nystrom, random features) scale SVMs a big data. Interpretability limited para non-linear kernels: decision function es complex combination of support vectors.

9.5 Árboles de Decisión: Modelos Jerárquicos Interpretables

Los árboles de decisión aprenden hierarchical sequences de reglas de decisión que recursively partition feature space en regions homogéneas respecto a target. La estructura de árbol consiste en internal nodes representando tests sobre features, branches representando outcomes de tests, y leaf nodes representando predictions (class labels para classification, valores para regression). Model interpretation es straightforward: seguir path desde root a leaf aplicando tests secuencialmente. Esta transparencia hace decision trees valiosos para dominios requiring explainability como healthcare, finance.

La construcción procede top-down greedy recursively: en cada node, seleccionar feature y threshold que "best" split data según purity criterion. Para classification, criterios incluyen: Gini impurity G = 1-∑pᵢ² measuring probability de misclassification; entropy H = -∑pᵢlog(pᵢ) desde information theory quantifying uncertainty; misclassification error 1-max(pᵢ). Information gain mide reduction en impurity: IG = H(parent) - ∑(nᵢ/n)H(child_i). Para regression, variance reduction optimiza: VR = Var(parent) - ∑(nᵢ/n)Var(child_i). Recursion continues hasta stopping criteria: maximum depth reached, minimum samples per node, purity threshold achieved. Different algorithms (ID3, C4.5, CART) vary en criteria y handling de continuous/categorical features.

Overfitting es concern major: unconstrained trees grow arbitrarily complex, memorizing training noise. Pruning techniques mitigate overfitting removing branches: pre-pruning stops growth early basándose en criteria (max depth, min samples); post-pruning grows full tree luego removes branches using validation set evaluating if removal improves generalization. Cost-complexity pruning balances tree size con training error via hyperparameter α. Feature importance scores quantify contribution de cada feature summing impurity decreases across all splits involving feature, guiding feature selection y interpretation. Handling missing values varies: some implementations skip instances con missing values, others surrogate splits using correlated features. Categorical features with many levels pueden dominate splits; grouping categories o using specialized algorithms (LightGBM) addresses this.

9.6 Naive Bayes: Clasificación Probabilística Bayesiana

Los clasificadores Naive Bayes aplican teorema de Bayes P(C|X) = P(X|C)P(C)/P(X) con "naive" assumption de conditional independence entre features dado class: P(X|C) = ∏P(xᵢ|C). Esto simplifica estimation dramatically: instead de estimating full joint distribution P(x₁,...,xₙ|C) requiring exponential parameters, estimate univariate distributions P(xᵢ|C) individually requiring linear parameters. Aunque independence assumption frecuentemente violated en practice, Naive Bayes surprisingly effective, often rivaling sophisticated methods especialmente con limited data.

Variantes adaptan a different feature types: Gaussian Naive Bayes assumes continuous features distribuidas normalmente, estimating mean μ y variance σ² per feature per class; prediction evaluates Gaussian density. Multinomial Naive Bayes handles discrete counts (word counts en text), modeling P(xᵢ|C) via multinomial distribution; Laplace smoothing añade pseudocounts evitando zero probabilities. Bernoulli Naive Bayes models binary features, estimating P(feature=1|C). Training extremely fast: count frequencies, compute probabilities. Prediction computes posterior probabilities for each class, selecting maximum (MAP: Maximum A Posteriori). Log probabilities prevent numerical underflow: log P(C|X) ∝ log P(C) + ∑log P(xᵢ|C).

Applications destacan en text classification: spam filtering (words as features), sentiment analysis, document categorization. Simplicity, speed, y effectiveness con high-dimensional sparse data hacen Naive Bayes attractive baseline. Challenges incluyen violated independence assumption reducing accuracy cuando features strongly correlated; poor probability estimates aunque classifications often correct (calibration issue). Continuous features requieren choosing distributional family; Gaussian assumption may not hold. Zero-frequency problem donde unseen feature-class combinations have zero probability addressed via smoothing. Despite limitations, Naive Bayes remains popular para large-scale text applications, real-time systems requiring fast predictions, y baselines establishing performance floors para complex methods.

9.7 Ensemble Methods: Combinando Múltiples Modelos

Los ensemble methods combinan predictions desde múltiples base learners achieving superior performance versus single models leveraging "wisdom of crowds": diverse models make different errors; averaging reduces variance. Bagging (Bootstrap AGGregating) trains models independently en bootstrap samples (random sampling con replacement desde training data), aggregating predictions via majority voting (classification) o averaging (regression). Independently trained models exhibit low correlation; errors partially cancel when aggregated. Bagging particularly effective reducing variance de high-variance models (eg. deep decision trees) sin significantly increasing bias. Out-of-bag samples (instances excluded desde bootstrap sample) serve como validation set estimating generalization error sin separate validation set.

Random Forests extend bagging a decision trees adding extra randomness: at each split, select best feature desde random subset rather que all features. This decorrelates trees further: if strong predictor exists, all bagged trees might use it in top splits correlating predictions; random feature subsets force diversity exploring alternative predictors. Hyperparameters incluyen number of trees (more generally better pero plateaus), max features per split (√n para classification, n/3 para regression common defaults), tree depth, min samples per leaf. Feature importance aggregated across trees identifies influential predictors. Extremely Randomized Trees (Extra Trees) randomize thresholds additionally, sampling random thresholds rather que optimizing, further reducing variance. Random Forests achieve state-of-the-art performance en tabular data, robust to overfitting, handle mixed feature types, require minimal tuning. Interpretability suffers versus single trees; partial dependence plots visualize feature effects.

Boosting trains models sequentially, each correcting errors de predecessors. AdaBoost adjusts instance weights: incorrectly classified instances receive higher weights; subsequent models focus on hard examples. Final prediction combines weighted models. Gradient Boosting generalizes boosting via gradient descent en function space: fit additive model F(x) = ∑fₜ(x) where each fₜ predicts negative gradient of loss function evaluated en current model. GBDT (Gradient Boosted Decision Trees) uses shallow trees como base learners. XGBoost, LightGBM, CatBoost implement optimized GBDT with regularization, efficient algorithms, handling categorical features. Hyperparameters incluyen learning rate (shrinkage reducing each tree's contribution), number of trees (more risks overfitting requiring early stopping), tree depth, subsampling (stochastic gradient boosting). Boosting achieves excellent performance competing con deep learning en structured data, winning Kaggle competitions. Overfitting risk requires careful tuning, early stopping based on validation performance. Interpretability limited pero feature importance y SHAP values aid explanation.

9.8 Evaluación de Modelos de Clasificación

La evaluación rigurosa de classification models requiere métricas comprehensivas capturando different aspects de performance. Accuracy = (TP+TN)/(TP+TN+FP+FN) mide overall correctness pero engañosa con imbalanced classes donde predicting majority class achieves high accuracy sin learning useful patterns. Confusion matrix tabula True Positives (TP), True Negatives (TN), False Positives (FP), False Negatives (FN) revealing error types. Precision = TP/(TP+FP) measures correctness de positive predictions (how many predicted positives are actual positives?). Recall (Sensitivity, True Positive Rate) = TP/(TP+FN) measures completeness capturing actual positives (how many actual positives are predicted?). Precision-recall tradeoff exists: increasing threshold for positive prediction increases precision pero decreases recall.

F1-score = 2·(Precision·Recall)/(Precision+Recall) harmonizes precision y recall balancing both. Fβ-score generaliza weighting recall β times más than precision. Specificity (True Negative Rate) = TN/(TN+FP) measures correctly identifying negatives. ROC (Receiver Operating Characteristic) curve plots TPR versus FPR (False Positive Rate = FP/(FP+TN)) across classification thresholds visualizing trade-off. AUC (Area Under ROC Curve) summarizes ROC en single score: 1.0 perfect, 0.5 random guessing. AUC interpreta como probability que model ranks random positive higher que random negative. PR (Precision-Recall) curve preferable para imbalanced datasets donde negatives vastly outnumber positives; ROC curves pueden engañar appearing optimistic.

El multiclass evaluation extends binary metrics via averaging: macro-averaging computes metric per class luego averages (treats classes equally); micro-averaging aggregates TP, FP, FN across classes luego computes (weights by class frequency); weighted averaging weights class metrics by support. Kappa statistic measures agreement beyond chance: κ = (p_o - p_e)/(1 - p_e) where p_o es observed agreement, p_e expected agreement by chance. Cross-validation assesses generalization: K-fold splits data en K folds, training en K-1, validating en held-out fold, rotating; average performance estimates expected performance en unseen data. Stratified K-fold preserves class proportions en folds critical para imbalanced data. Nested cross-validation separates hyperparameter tuning desde model evaluation preventing optimistic bias.

9.9 Evaluación de Modelos de Regresión

Los regression models evaluados mediante error metrics quantifying prediction accuracy. Mean Absolute Error MAE = (1/n)∑|yᵢ-ŷᵢ| averages absolute errors, interpretable en units de target, robust a outliers pero non-differentiable at zero. Mean Squared Error MSE = (1/n)∑(yᵢ-ŷᵢ)² squares errors emphasizing large errors, differentiable facilitating optimization, sensitive a outliers. Root Mean Squared Error RMSE = √MSE restores original units being more interpretable. R² (coefficient of determination) = 1 - SS_res/SS_tot measures proportion of variance explained: 1.0 perfect fit, 0 baseline (mean prediction), negative worse than baseline. Adjusted R² penalizes model complexity preventing inflated scores desde adding irrelevant features.

Mean Absolute Percentage Error MAPE = (100/n)∑|(yᵢ-ŷᵢ)/yᵢ| expresses error as percentage, interpretable, scale-independent pero undefined cuando yᵢ=0 y biased towards underforecasts. Residual analysis examines prediction errors: plotting residuals versus predictions reveals patterns (heteroscedasticity, non-linearity); normal probability plot checks normality assumption. Cross-validation for regression uses same K-fold strategy, averaging metrics. Prediction intervals quantify uncertainty: confidence intervals for mean predictions; prediction intervals for individual predictions (wider accounting for individual variability). Metrics selection depends on context: RMSE penalizes large errors appropriate cuando costly; MAE treats errors equally appropriate cuando errors equally undesirable.

9.10 Selección de Características y Reducción de Dimensionalidad

La feature selection identifica subconjunto de relevant features improving model performance, interpretability, reducing training time. Filter methods rank features independently de model usando statistical tests: correlation con target, mutual information, chi-squared test, ANOVA F-test. Fast pero ignoran feature interactions. Wrapper methods evaluate feature subsets usando model performance: forward selection iteratively adds best feature; backward elimination removes worst; recursive feature elimination (RFE) repeatedly trains model, removes least important features. Computationally expensive pero consider interactions. Embedded methods perform selection during training: L1 regularization induces sparsity; tree-based feature importance ranks features by contribution; linear model coefficients indicate importance.

La dimensionality reduction transforma features a lower-dimensional space preservando information. PCA (Principal Component Analysis) finds orthogonal directions of maximum variance projecting data; components are linear combinations of original features. Unsupervised, fast, pero components may not align con supervised task. LDA (Linear Discriminant Analysis) finds projection maximizing class separation supervised approach. Feature engineering creates new features capturing domain knowledge: polynomial features, interactions, domain-specific transformations often improving performance dramatically. The curse of dimensionality afflicts high-dimensional data: sparsity, distance concentration, computational cost motivate dimensionality reduction especially para k-NN, clustering. Regularization implicitly performs selection shrinking coefficients; combining explicit selection con regularization balances interpretability con performance.

Puntos Clave de la Clase

  • La regresión lineal modela relaciones lineales optimizando MSE; regularization (Ridge, Lasso) previene overfitting
  • La regresión logística modela probabilidades de clasificación mediante función sigmoid y maximum likelihood
  • k-NN clasifica basándose en vecinos cercanos; selección de k balancea bias-variance; scaling crítico
  • SVM maximiza margen para robustez; kernel trick habilita fronteras no lineales implicitamente
  • Los árboles de decisión aprenden reglas jerárquicas interpretables; pruning previene overfitting
  • Naive Bayes aplica teorema de Bayes con independence assumption; rápido, efectivo para text
  • Bagging reduce variance promediando models; Random Forests añade randomness decorrelating trees
  • Boosting corrige errors secuencialmente; Gradient Boosting optimiza via gradient descent achieving SOTA
  • Las métricas de evaluación incluyen accuracy, precision, recall, F1, ROC-AUC para classification; MAE, RMSE, R² para regression
  • Feature selection y dimensionality reduction mejoran performance, interpretability, efficiency
