Clase 4: Algoritmos y Estructuras de Datos en Inteligencia Artificial

4.1 Complejidad Algorítmica y Análisis Asintótico

El análisis de complejidad algorítmica constituye una competencia fundamental para el desarrollo de sistemas de inteligencia artificial eficientes y escalables. La notación Big-O proporciona un formalismo para caracterizar cómo el tiempo de ejecución o el uso de memoria de un algoritmo escala en función del tamaño de la entrada. Un algoritmo con complejidad O(n) exhibe crecimiento lineal: duplicar el tamaño de entrada aproximadamente duplica el tiempo de ejecución. Los algoritmos O(n²) cuadráticos, comunes en implementaciones naivas de problemas comparativos, se tornan rápidamente impracticables para grandes volúmenes de datos.

La complejidad logarítmica O(log n), característica de algoritmos que iterativamente dividen el espacio de búsqueda (como búsqueda binaria en arrays ordenados), escala extraordinariamente bien: incluso para entradas masivas, el número de operaciones crece modestamente. Los algoritmos O(n log n), tipificados por algoritmos de ordenamiento eficientes como MergeSort y QuickSort, representan frecuentemente el óptimo alcanzable para problemas comparativos en el modelo de computación general. La complejidad exponencial O(2ⁿ) y factorial O(n!) caracteriza problemas intratables donde enumeración exhaustiva resulta inevitable, motivando aproximaciones heurísticas y aleatorias.

El análisis amortizado proporciona una perspectiva más sofisticada, caracterizando el costo promedio de operaciones en secuencias, reconociendo que operaciones individuales costosas pueden ser subsidiadas por operaciones baratas frecuentes. Las estructuras de datos dinámicas como tablas hash con expansión dinámica exhiben esta propiedad: aunque la expansión individual sea costosa (O(n)), su frecuencia se controla de manera que el costo amortizado por inserción permanece constante.

En el contexto de machine learning, la complejidad computacional determina la factibilidad de entrenar y desplegar modelos. Los algoritmos de entrenamiento de redes neuronales mediante backpropagation tienen complejidad lineal en el número de parámetros y el tamaño del conjunto de entrenamiento, haciendo practicable el entrenamiento de modelos con millones de parámetros. Sin embargo, arquitecturas como redes neuronales recurrentes (RNNs) exhiben limitaciones inherentes de paralelización debido a dependencias secuenciales, motivando el desarrollo de arquitecturas alternativas como Transformers que sacrifican complejidad por muestra (O(n²) respecto a longitud de secuencia) para ganar paralelización masiva.

4.2 Estructuras de Datos Fundamentales para IA

Las estructuras de datos apropiadas constituyen el fundamento de implementaciones eficientes de algoritmos de IA. Los arrays y listas enlazadas representan las estructuras secuenciales más básicas: arrays proporcionan acceso en tiempo constante mediante indexación pero requieren memoria contigua y tienen costo lineal para inserciones; listas enlazadas facilitan inserciones eficientes pero requieren recorrido secuencial para acceso. La elección entre estas alternativas depende del patrón de acceso predominante en la aplicación específica.

Las pilas (stacks) y colas (queues) implementan disciplinas LIFO y FIFO respectivamente, fundamentando algoritmos de búsqueda en grafos: búsqueda en profundidad (DFS) emplea pilas para rastrear nodos a explorar, mientras que búsqueda en amplitud (BFS) utiliza colas. Las colas de prioridad, típicamente implementadas mediante heaps binarios, mantienen elementos ordenados por prioridad permitiendo extracción eficiente del elemento máximo (o mínimo). Esta estructura fundamenta el algoritmo A* de búsqueda informada, donde se exploran nodos en orden de estimación de costo total al objetivo.

Las tablas hash proporcionan acceso, inserción y eliminación en tiempo constante promedio mediante funciones hash que mapean claves a índices de array. Colisiones, donde claves distintas generan el mismo hash, se resuelven mediante encadenamiento (listas enlazadas en cada bucket) o direccionamiento abierto (búsqueda de buckets alternativos). Las tablas hash fundamentan diccionarios y conjuntos en lenguajes de programación modernos, estructuras ubicuas en implementaciones de IA para almacenar vocabularios, cachés de cómputos intermedios, y mapeos arbitrarios.

Los árboles balanceados (AVL, Red-Black trees) mantienen datos ordenados permitiendo búsqueda, inserción y eliminación en tiempo logarítmico, garantizando balance mediante rotaciones durante modificaciones. Los árboles de decisión, centrales en machine learning clásico, particionen recursivamente el espacio de características mediante predicados sobre atributos, representando funciones de clasificación mediante estructura jerárquica interpretable. Los random forests ensemble múltiples árboles de decisión entrenados en muestras bootstrap de datos, combinando sus predicciones mediante votación o promediado para robustez y generalización superiores.

4.3 Algoritmos de Búsqueda: Navegando Espacios de Soluciones

Los algoritmos de búsqueda constituyen una clase fundamental de métodos para resolver problemas de IA que pueden formularse como exploración de espacios de estados. Un espacio de estados consiste en un estado inicial, un conjunto de operadores que transforman estados, y un test de objetivo que identifica estados meta. El problema de búsqueda consiste en encontrar una secuencia de operadores que transforme el estado inicial en un estado objetivo, idealmente minimizando algún costo acumulado.

La búsqueda no informada explora el espacio sin información adicional sobre proximidad al objetivo. Búsqueda en amplitud (BFS) expande nodos capa por capa, garantizando encontrar la solución con menor número de pasos pero potencialmente requiriendo memoria exponencial. Búsqueda en profundidad (DFS) explora ramas completas antes de retroceder, usando memoria lineal en la profundidad pero sin garantías de optimalidad. La búsqueda de profundidad iterativa (IDS) combina las ventajas de ambos enfoques, repetidamente ejecutando DFS con límites de profundidad incrementales, alcanzando completitud de BFS con eficiencia de memoria de DFS.

La búsqueda informada explota funciones heurísticas que estiman el costo al objetivo desde cada estado, priorizando la exploración de regiones prometedoras del espacio. El algoritmo A* mantiene para cada nodo n una estimación f(n) = g(n) + h(n), donde g(n) es el costo acumulado desde el inicio hasta n, y h(n) es la heurística que estima el costo de n al objetivo. A* explora nodos en orden creciente de f, garantizando encontrar soluciones óptimas cuando la heurística es admisible (nunca sobreestima el costo verdadero) y consistente (respeta la desigualdad triangular).

Las heurísticas efectivas pueden acelerar dramáticamente la búsqueda, reduciendo nodos explorados en órdenes de magnitud. En el problema de las n-reinas, la heurística de conflictos mínimos guía hacia configuraciones con menos ataques. En planificación automatizada, las heurísticas de eliminación de precondiciones estiman pasos requeridos ignorando interacciones entre subobjetivos. El diseño de heurísticas admisibles pero informativas constituye un arte que balancea tratabilidad computacional con potencia discriminatoria.

4.4 Algoritmos de Ordenamiento y su Relevancia en IA

El ordenamiento, problema computacional fundamental, encuentra numerosas aplicaciones en inteligencia artificial. Los algoritmos de ordenamiento simples —como SelectionSort, InsertionSort y BubbleSort— exhiben complejidad cuadrática O(n²), resultando practicables solo para conjuntos pequeños. InsertionSort, no obstante, muestra eficiencia excepcional para datos casi ordenados, propiedad aprovechada en algoritmos híbridos.

MergeSort ejemplifica el paradigma divide-y-vencerás: recursivamente divide el array en mitades, ordena cada mitad independientemente, y fusiona los resultados ordenados. Esta estrategia garantiza complejidad O(n log n) en todos los casos, óptimo para ordenamiento basado en comparaciones. MergeSort requiere espacio auxiliar O(n) para la fusión, consideración relevante para aplicaciones con restricciones de memoria. Su estructura naturalmente paralela permite implementaciones eficientes en arquitecturas de memoria compartida y distribuida.

QuickSort, alternativa in-place a MergeSort, selecciona un pivote, particiona el array reordenando elementos menores que el pivote antes y mayores después, y recursivamente ordena las particiones. Con pivotes bien elegidos, QuickSort alcanza complejidad promedio O(n log n), típicamente superando MergeSort en la práctica debido a mejores constantes y localidad de memoria. Sin embargo, el peor caso (O(n²) con pivotes sistemáticamente mal elegidos) requiere estrategias de selección de pivote aleatorias o deterministas sofisticadas.

En contextos de machine learning, el ordenamiento facilita numerosas operaciones: identificar k-vecinos más cercanos en k-NN, calcular medianas para imputación de datos faltantes, ordenar características por importancia para selección de atributos, y determinar umbrales óptimos en árboles de decisión. Los algoritmos de selección, que encuentran el k-ésimo elemento más pequeño sin ordenar completamente (QuickSelect, MedianOfMedians), ofrecen complejidad lineal promedio, superiores cuando solo se requiere identificar elementos específicos en lugar de ordenamiento completo.

4.5 Algoritmos Probabilísticos y de Aproximación

Muchos problemas relevantes para IA son NP-completos o NP-duros, implicando que ningún algoritmo eficiente (polinomial) se conoce ni se espera existir para resolverlos exactamente en el peor caso. Para estos problemas, algoritmos probabilísticos y de aproximación ofrecen soluciones practicables sacrificando garantías absolutas por eficiencia computacional. Los algoritmos de Monte Carlo producen respuestas que pueden ser incorrectas con probabilidad controlada, mientras que algoritmos de Las Vegas siempre producen respuestas correctas pero su tiempo de ejecución varía aleatoriamente.

Los algoritmos de muestreo probabilístico aproximan distribuciones de probabilidad complejas generando muestras aleatorias que asintóticamente reflejan la distribución objetivo. El muestreo de Monte Carlo por Cadenas de Markov (MCMC), particularmente el algoritmo de Metropolis-Hastings y el muestreador de Gibbs, construye cadenas de Markov cuya distribución estacionaria coincide con la distribución objetivo. Estos métodos fundamentan la inferencia bayesiana aproximada, permitiendo razonamiento probabilístico en modelos donde la inferencia exacta es intratable.

Los algoritmos evolutivos y genéticos aplican metáforas de evolución biológica para optimización global. Una población de soluciones candidatas evoluciona mediante operadores de selección (favorecer individuos con mejor fitness), crossover (combinar características de padres) y mutación (introducir variación aleatoria). Aunque sin garantías de optimalidad, estos algoritmos demuestran efectividad en espacios de búsqueda vastos, multimodales y discontinuos donde métodos basados en gradientes fallan.

El templado simulado (Simulated Annealing) emula el proceso físico de templado metalúrgico, donde el sistema se calienta y enfría gradualmente para alcanzar configuraciones de mínima energía. El algoritmo acepta probabilísticamente movimientos que empeoran la función objetivo con probabilidad decreciente a medida que avanza, escapando mínimos locales y explorando el espacio global. La búsqueda tabú mantiene memoria de regiones recientemente exploradas, prohibiendo temporalmente revisitas para forzar exploración diversa del espacio de búsqueda.

4.6 Paralelización y Algoritmos Distribuidos en IA

El advenimiento de procesadores multinúcleo, GPUs masivamente paralelas, y sistemas de computación distribuida ha transformado la implementación de algoritmos de inteligencia artificial. La paralelización explota múltiples unidades de procesamiento ejecutando computaciones concurrentemente, potencialmente reduciendo tiempo de ejecución proporcional al número de procesadores. Sin embargo, no todos los algoritmos son inherentemente paralelizables: la Ley de Amdahl formaliza que la aceleración máxima está limitada por la fracción secuencial del programa: Speedup ≤ 1 / (s + p/N) donde s es fracción secuencial, p fracción paralela, N número de processors. Even con infinite processors, speedup bounded por 1/s. Ley de Gustafson ofrece perspectiva más optimista: con problem size scaling, parallel portion dominates enabling better scaling.

El entrenamiento de redes neuronales profundas se paraleliza naturalmente en múltiples dimensiones. El paralelismo de datos (data parallelism) replica el modelo en múltiples dispositivos, procesando mini-batches diferentes simultáneamente y agregando gradientes para actualización de parámetros via all-reduce operations. Este enfoque escala casi linealmente con el número de dispositivos cuando la comunicación de gradientes no domina el tiempo total. Ring all-reduce y tree-based reduction minimize communication overhead. El paralelismo de modelo (model parallelism) particiona el propio modelo entre dispositivos cuando es demasiado grande para memoria de un solo dispositivo: capas diferentes ejecutan en dispositivos diferentes requiriendo comunicación frecuente de activaciones forward y gradients backward entre particiones. Pipeline parallelism overlaps computation de diferentes microbatches across pipeline stages mejorando utilization.

Las GPUs (Graphics Processing Units), originalmente diseñadas para renderizado gráfico, han emergido como aceleradores dominantes para deep learning debido a su arquitectura SIMD (Single Instruction, Multiple Data) con miles de núcleos simples ejecutando operations en parallel. Operaciones matriciales masivas características de redes neuronales (matrix multiplications, convolutions, elementwise operations) se mapean naturalmente a esta arquitectura, alcanzando speedups de 10-100x comparado con CPUs multi-core. CUDA y cuDNN libraries from NVIDIA provide optimized primitives. Las TPUs (Tensor Processing Units) de Google representan hardware especializado diseñado específicamente para operaciones de IA con systolic arrays optimizando matrix multiplications, mixed precision arithmetic (FP16/BF16), y high memory bandwidth minimizing data movement, achieving superior energy efficiency y throughput for training/inference at scale.

Los frameworks de computación distribuida como Apache Spark y Hadoop permiten procesar datasets que exceden la memoria de máquinas individuales, distribuyendo datos y computación en clusters con hundreds/thousands de nodes. MapReduce, paradigma de programación subyacente, expresa computations como operaciones de mapeo (aplicar función a cada elemento independientemente producing key-value pairs) y reducción (agregar resultados per key), garantizando tolerancia a fallos via replication y task re-execution, y escalabilidad horizontal adding more nodes. Algoritmos de machine learning como regresión lineal (gradient computed distributedly), k-means clustering (assignment y centroid update parallelizable), y árboles de decisión (parallel feature/split evaluation) admiten formulaciones MapReduce eficientes, democratizando análisis de big data. Parameter servers architecturally separate computation nodes (workers) desde storage nodes (servers) holding shared parameters enabling asynchronous updates scaling to billions de parameters.

4.7 Algoritmos de Grafos: Caminos, Flujos y Conectividad

Los algoritmos de grafos address problemas fundamentales en estructuras relacionales ubicuas en AI: social networks, knowledge graphs, dependency graphs, neural network architectures. El algoritmo de Dijkstra finds shortest paths desde source node a all others en graphs con edge weights non-negative mediante greedy strategy: iteratively select unvisited node con smallest tentative distance, update distances a neighbors, mark as visited. Complexity O(|E| + |V| log |V|) with priority queue. Bellman-Ford handles negative weights detecting negative cycles, complexity O(|V||E|). A* search extends Dijkstra incorporating heuristic function h(n) estimating distance to goal, exploring nodes con lowest f(n) = g(n) + h(n) donde g(n) es actual distance desde source. With admissible heuristic (h never overestimates), A* guarantees optimal paths being more efficient que Dijkstra.

Floyd-Warshall computes all-pairs shortest paths via dynamic programming: iteratively consider paths through intermediate nodes, updating distances matrix. Complexity O(|V|³) suitable para dense graphs. Maximum flow algorithms find maximum flow desde source a sink in flow networks: Ford-Fulkerson method iteratively finds augmenting paths increasing flow, terminating cuando no augmenting path exists (max-flow min-cut theorem). Edmonds-Karp implements Ford-Fulkerson using BFS ensuring polynomial O(|V||E|²) complexity. Push-relabel algorithms achieve better O(|V|²|E|) performance. Applications include bipartite matching, network optimization, image segmentation via min-cut.

Minimum spanning trees connect all vertices with minimum total edge weight: Prim's algorithm grows MST desde arbitrary vertex greedily adding minimum edge connecting tree to non-tree vertex, O(|E| + |V| log |V|). Kruskal's algorithm sorts edges by weight, iteratively adds edges that don't create cycles using union-find data structure, O(|E| log |V|). Connectivity algorithms determine strongly connected components (SCCs) en directed graphs: Kosaraju's algorithm runs DFS twice computing finish times, transposed graph processed en decreasing finish time. Tarjan's algorithm uses single DFS with stack tracking SCCs online. Applications en compiler optimization (dependency analysis), web crawling (identifying related pages), social network analysis (community detection).

4.8 Algoritmos de Aproximación y Heurísticas Clásicas

Los algoritmos de aproximación provide provable guarantees para problems NP-hard: solution quality bounded by factor de optimal. Vertex cover problem (find minimum vertices covering all edges): greedy algorithm repeatedly selects edge, adds both endpoints to cover, removes covered edges achieves 2-approximation (solution at most twice optimal). Set cover (cover universe con minimum subsets): greedy algorithm iteratively selects set covering most uncovered elements achieves O(log n)-approximation. Traveling salesman problem (TSP): metric TSP (satisfying triangle inequality) admits 2-approximation via MST-based algorithm constructing tour from minimum spanning tree, 1.5-approximation via Christofides algorithm adding minimum matching to MST.

Las metaheurísticas provide general frameworks applicable across diverse problems sin problem-specific guarantees. Hill climbing iteratively moves a neighboring solution con better objective value, terminating at local optimum potentially far desde global optimum. Random restart hill climbing executes multiple runs desde random initial states increasing probability finding good solution. Las colony optimization mimics foraging behavior: artificial ants deposit pheromones on paths, pheromone levels influence subsequent ants' path selection, positive feedback concentrates on good solutions. Successful for TSP, vehicle routing, scheduling.

Particle swarm optimization simulates social behavior: particles represent solutions moving en search space influenced por personal best position y global best position discovered, balancing exploration (global best) con exploitation (personal best). Harmony search mimics musical improvisation: solutions analogous a harmonies, new solutions generated combining existing solutions con randomization. Variable neighborhood search systematically explores different neighborhood structures escaping local optima. Iterated local search perturbates locally optimal solutions then applies local search repeatedly. Hybrid approaches combine metaheuristics con problem-specific procedures y machine learning for adaptive parameter tuning achieving state-of-the-art performance en complex optimization problems arising en logistics, scheduling, resource allocation, configuration spaces.

4.9 Algoritmos Online y Streaming

Los algoritmos online process input arriving sequentially making irrevocable decisions sin knowledge de future inputs, crucial para real-time systems. Competitive analysis compares online algorithm performance to optimal offline algorithm knowing entire input: algorithm is c-competitive si cost ≤ c × optimal + constant. Caching problem (maintain subset de data en limited cache): Least Recently Used (LRU) evicts least recently accessed item, achieving O(k)-competitive ratio where k es cache size proven optimal for deterministic algorithms. Randomized marking algorithm achieves better 2ln(k)-competitive ratio.

Los streaming algorithms process massive data streams using sublinear space (typically logarithmic o polylogarithmic en stream size) making single pass. Counting distinct elements: exact counting requires linear space; Flajolet-Martin algorithm estimates cardinality using O(log n) space hashing elements tracking minimum hash value. HyperLogLog improves accuracy partitioning hash space averaging estimates. Frequency estimation: Count-Min Sketch maintains array de counters hashed con multiple hash functions estimating frequencies con bounded error probabilistically. Applications en network traffic analysis, database query optimization, real-time analytics.

Reservoir sampling maintains uniform random sample de k elements desde stream de unknown length: first k elements added to reservoir, subsequent element i included con probability k/i replacing random reservoir element. Proves each element equally likely in final sample. Sliding window algorithms maintain statistics over recent w elements: time-based (elements within time interval) o count-based (last w elements). Exponentially weighted moving averages efficiently track trends weighting recent observations more heavily. Online learning algorithms update models incrementally as data arrives: stochastic gradient descent updates parameters per sample, online convex optimization guarantees regret bounds. Essential para adaptive systems learning from user interactions, sensor data streams, financial tick data requiring real-time responsiveness.

4.10 Algoritmos de Compresión y Codificación

La compresión de datos reduce storage requirements y communication bandwidth essential para AI systems handling massive datasets. Lossless compression preserves information perfectly enabling exact reconstruction: Huffman coding builds optimal prefix-free code assigning shorter codes to frequent symbols achieving entropy bound. Arithmetic coding encodes entire message as single number within interval, asymptotically achieving entropy. Lempel-Ziv algorithms (LZ77, LZ78, LZW) identify repeated substrings replacing with backreferences achieving excellent compression for text without prior statistics. Used en GIF, PNG, ZIP formats.

Lossy compression discards information imperceptible o less important achieving higher compression ratios: JPEG compresses images via discrete cosine transform converting spatial data to frequency domain, quantizing high-frequency components less precisely (human vision less sensitive), entropy coding remaining. MP3 compresses audio exploiting psychoacoustic masking removing inaudible frequencies. Video compression (H.264, H.265, VP9) exploits temporal y spatial redundancy: motion compensation predicts frames from previous frames, transform coding compresses residuals, adaptively partitioning frames optimizing rate-distortion tradeoff. Neural compression using autoencoders y generative models achieving competitive rates con learned representations.

Error-correcting codes add redundancy enabling detection y correction de transmission errors critical for reliable communication y storage. Hamming codes add parity bits detecting y correcting single-bit errors efficiently. Reed-Solomon codes widely used en CDs, DVDs, QR codes correcting burst errors via polynomial evaluation over finite fields. Low-Density Parity-Check (LDPC) codes y Turbo codes achieve near-Shannon capacity performance using iterative decoding approaches. Checksums y cryptographic hashes (MD5, SHA families) detect data corruption efficiently. Bloom filters probabilistic data structure testing set membership con false positives possible pero false negatives impossible, space-efficient for large sets useful en database query optimization, network routers, spell checkers, web caches.
