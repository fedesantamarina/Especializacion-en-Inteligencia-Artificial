# Diplomado en Inteligencia Artificial - Liskov Ed Tech

Sitio web educativo interactivo con 16 clases académicas sobre Inteligencia Artificial, desarrollado por Liskov Ed Tech para formar profesionales en IA.

## Características

- **16 clases completas** de aproximadamente 2000 palabras cada una
- **Contenido académico riguroso** sobre fundamentos y aplicaciones de IA
- **Diagramas interactivos** con Mermaid para visualización de conceptos
- **Navegación intuitiva** con barra lateral y contenido central
- **Diseño responsive** adaptable a diferentes dispositivos
- **Tono académico profesional** apropiado para educación universitaria

## Estructura del Curso

### Módulo 1: Fundamentos de IA (Clases 1-4)
- Clase 1: Introducción a la Inteligencia Artificial
- Clase 2: Historia y Evolución de la IA
- Clase 3: Fundamentos Matemáticos para IA
- Clase 4: Algoritmos y Estructuras de Datos en IA

### Módulo 2: Representación del Conocimiento (Clases 5-7)
- Clase 5: Representación de Conocimiento
- Clase 6: Razonamiento y Lógica en IA
- Clase 7: Ontologías y Bases de Conocimiento

### Módulo 3: Aprendizaje Automatizado (Clases 8-11)
- Clase 8: Introducción al Machine Learning
- Clase 9: Aprendizaje Supervisado - Algoritmos Clásicos
- Clase 10: Aprendizaje No Supervisado
- Clase 11: Deep Learning y Redes Neuronales

### Módulo 4: Aplicaciones Avanzadas (Clases 12-14)
- Clase 12: Procesamiento de Lenguaje Natural
- Clase 13: Visión por Computadora
- Clase 14: Agentes Inteligentes y Sistemas Multiagente

### Módulo 5: IA en la Práctica (Clases 15-16)
- Clase 15: Ética y Consideraciones Sociales en IA
- Clase 16: Proyectos y Aplicaciones Reales de IA

## Cómo usar

1. **Abrir el sitio**: Simplemente abre `index.html` en tu navegador web
2. **Navegar**: Usa la barra lateral izquierda para seleccionar cualquier clase
3. **Leer**: El contenido de la clase seleccionada aparecerá en el panel central
4. **Visualizar**: Los diagramas Mermaid se renderizan automáticamente
5. **Navegación con teclado**: Usa las flechas izquierda/derecha para navegar entre clases

## Tecnologías utilizadas

- **HTML5**: Estructura del sitio
- **CSS3**: Estilos y diseño responsive
- **JavaScript**: Navegación dinámica y carga de contenido
- **Mermaid.js**: Generación de diagramas interactivos
- **Marked.js**: Procesamiento de markdown (opcional)

## Características de diseño

- **Header fijo**: Con título y navegación principal
- **Barra lateral sticky**: Acceso rápido a todos los módulos y clases
- **Contenido académico**: Formato profesional con heading jerarquizado
- **Diagramas visuales**: Mermaid para flowcharts, mindmaps, y timelines
- **Info boxes**: Resúmenes de puntos clave en cada clase
- **Referencias bibliográficas**: Enlaces a recursos académicos
