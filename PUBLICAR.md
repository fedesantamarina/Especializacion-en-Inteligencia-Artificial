# 🚀 Cómo Publicar el Sitio Web

## Pasos Simples (2 minutos)

### 1. Abre tu repositorio en GitHub
Ve a: https://github.com/fedesantamarina/Especializacion-en-Inteligencia-Artificial

### 2. Habilita GitHub Pages
1. Haz clic en **"Settings"** (⚙️ arriba a la derecha)
2. En el menú lateral izquierdo, busca **"Pages"**
3. En **"Build and deployment"**:
   - **Source**: Selecciona **"GitHub Actions"**
4. ¡Listo! No necesitas hacer nada más.

### 3. Espera 1-2 minutos
El sitio se publicará automáticamente.

### 4. Accede a tu sitio
Tu sitio estará en:
**https://fedesantamarina.github.io/Especializacion-en-Inteligencia-Artificial/**

## ❓ Preguntas Frecuentes

**Q: ¿Cuánto tarda?**
A: 1-2 minutos después de habilitar GitHub Pages.

**Q: ¿El sitio se actualiza solo?**
A: Sí, cada vez que hagas push a la rama, se actualizará automáticamente.

**Q: ¿Funciona sin hacer merge a main?**
A: Sí, el workflow está configurado para funcionar desde tu rama actual también.

**Q: ¿Puedo usar un dominio personalizado?**
A: Sí, en la misma página de Settings > Pages puedes configurar un dominio custom.
